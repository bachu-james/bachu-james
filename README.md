## Featured Projects

### 🤖 Autonomous Indoor Navigation Robot
> *ROS 2 · Nav2 · SLAM Toolbox · LiDAR*

Full autonomous navigation stack on a custom mobile robot. Implements simultaneous localization and mapping, dynamic obstacle avoidance via Nav2 costmaps, and goal-directed navigation using behavior trees.

- Real-time SLAM with SLAM Toolbox on RPLIDAR A1
- Tuned Nav2 DWB local planner for smooth obstacle avoidance
- Custom ROS 2 launch architecture for modular bringup

[![Repo](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/bachu-james)

---

### 🦾 PyBullet Pick-and-Place Simulation
> *PyBullet · MoveIt2 · IK · Synthetic Perception*

End-to-end manipulation pipeline with a Franka Panda robot in PyBullet. Five-phase grasp execution: scene setup → perception → IK solving → motion planning → grasp execution.

- Synthetic RGB-D camera for object pose estimation
- Custom IK pipeline with collision-aware trajectory planning
- Fully automated grasp-and-place loop

---

### 🗺️ Hybrid APF-RRT Motion Planner
> *Python · Path Planning · Robotics Algorithms*

Custom motion planner combining Artificial Potential Fields (APF) for reactive local guidance with RRT for global path exploration. Handles dynamic environments where pure APF gets stuck in local minima.

- Hybrid switching logic between global and local planners
- Visualized planning steps with Matplotlib
- Benchmarked against standalone RRT and APF

---

### 🎮 Haptic Dial PID Controller
> *Python · PID · Control Systems · Embedded*

PID-based force feedback system for a haptic dial. Smooth torque response with configurable stiffness, damping, and detent simulation. Tested against step and sinusoidal reference inputs.

---

### 🐘 Wildlife Hazard Detection System
> *YOLOv8 · OpenCV · LoRa · Edge AI*

Real-time wildlife detection at forest borders using YOLOv8 on edge hardware, with LoRa radio for long-range alerting. Built to reduce human-wildlife conflict in rural areas.

- Custom-trained YOLOv8 model for elephant detection
- LoRa-based alert relay across 2+ km range
- Deployed on Raspberry Pi with optimized inference

---

### 📡 RPLIDAR A1M8 — Real-Time Polar Visualization
> *Python · Matplotlib · Raspberry Pi*

Raw LiDAR scan visualization without ROS — direct serial communication with RPLIDAR A1M8, real-time polar plotting with Matplotlib, clean shutdown handling.
